# Chapter 6 — Phase 6C Evidence & Research Assistant V32

Status: **IMPLEMENTED — user-authorized after V31**.

## Scope

Phase 6C adds evidence collection, counter-evidence prompts and research-gap management for Shearn Q27–Q32. It is a research assistant, not an investment decision engine.

### Q27
- Revenue recognition, capitalization/expensing, depreciation/estimate changes, reserves/provisions, restructuring/impairment and audit evidence.
- Read-only bridge from Module 2 Financial Manipulation diagnostics: Beneish, Sloan/Accrual Quality, Modified Jones/Kothari and REM.
- Chapter 6 **does not recalculate** these manipulation models.

### Q28–Q32
- Q28: recurring/contracted/subscription/renewal/churn/backlog evidence.
- Q29: company-specific cycle/downturn/supply-demand/commodity evidence.
- Q30: fixed/variable/semi-variable cost and capacity-utilization evidence.
- Q31: receivable/inventory/payable/terms/advance working-capital mechanism evidence.
- Q32: maintenance/growth/regulatory capex, asset age and replacement evidence.

## Evidence quality

- **A — Company/Official disclosure**
- **B — Independent financial source/research**
- **C — Secondary/context source**
- **T — Trecapital Module 2 diagnostic** is an internal analytical diagnostic, not an A/B/C external-source grade.

Search results remain `Candidate — analyst verify`. Query text is never used as evidence; classification is based on returned title/snippet text.

## Immutable analyst boundary

Phase 6C must not automatically set or modify Conservative/Liberal accounting, recurring-revenue quality/share, cyclical/countercyclical/recession-resistant classification, operating-leverage risk conclusion, CCC sustainability, maintenance capex, earnings-distribution width, MOS, Research Gate, or BUY/HOLD/SELL.

## TTM boundary

Financial time-series displays extend through TTM when a valid canonical TTM row exists. Annual-only models such as Beneish/Jones/REM show the latest valid annual result and an explicit **TTM = N/A / methodology guardrail** row rather than fabricating a TTM model value.
