# Formula Explanation — Appendix C Phase A / V96

## No new financial formulas

Appendix C contains **no new financial formula**. Michael Shearn's Appendix C is a consolidated list of Q01–Q59, so V96 deliberately does not recalculate ROIC, cash flow, working capital, balance-sheet measures, growth, acquisition economics, intrinsic value, Margin of Safety, or any other financial metric.

Any financial number displayed by a later Appendix C view must be read from the existing canonical financial/data SSOT used by the owning Deep Company Analysis chapter. Existing unit, decimal, table, chart, and negative-number formatting rules remain authoritative.

## Referential mapping

For checklist item `Qxx`:

`Appendix C item -> ssot_reference = Qxx -> owning DCA chapter/state`

The reference is identity-only. Appendix C does not persist a copy of the answer, evidence, confidence, research status, financial payload, valuation state, or analyst conclusion.

## Deterministic counts

The only deterministic arithmetic in V96 is structural validation of source coverage:

- Question count = `59`.
- Section count = `10`.
- Section counts = `6 + 8 + 6 + 6 + 6 + 6 + 9 + 5 + 5 + 2 = 59`.
- Question identifiers = continuous `Q01 ... Q59` in printed Appendix C order.

These counts are source-integrity checks, not scores, weights, ratings, or investment signals.

## Prohibited derivations

V96 does not derive:

- weighted checklist/management/growth scores;
- checklist completion -> business quality;
- checklist completion -> BUY/HOLD/SELL;
- checklist completion -> intrinsic value or MOS change;
- checklist completion -> Investment Research Gate change;
- missing source material -> AI-generated answer.

AI remains **Research Assistant** and the analyst owns conclusions.
