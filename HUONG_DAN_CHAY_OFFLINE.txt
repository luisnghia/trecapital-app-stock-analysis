TREC CAPITAL - PHAN TICH CHUYEN SAU DOANH NGHIEP
=================================================

GOI NAY DUOC DONG GOI DE CHAY OFFLINE TREN WINDOWS 64-BIT CO PYTHON 3.11.
Khong can Git, khong can clone repo, khong can Internet de cai thu vien Python.

CACH CHAY NHANH
1. Tai file Trecapital_Deep_Analysis_Offline_V1.zip.
2. Giai nen ra mot thu muc rieng.
3. Double-click: CHAY_TRECAPITAL_OFFLINE.bat
4. Neu may chua co thu vien, launcher se tu cai tu thu muc offline_wheels kem theo.
5. Trinh duyet se mo Trecapital.
6. Chon menu: Phan tich chuyen sau doanh nghiep.

YEU CAU DUY NHAT
- Windows 64-bit.
- Python 3.11 64-bit da cai va lenh python co trong PATH.

NEU MUON CAI THU VIEN THU CONG
- Double-click CAI_THU_VIEN_MOT_LAN.bat.
- Script chi dung offline_wheels trong goi, khong truy cap Internet.

DU LIEU CHUONG 1
- Luu local bang SQLite tai data_cache/deep_company_analysis_chapter1.db.
- Khong can OpenAI API, Supabase hay Internet de nhap, luu va mo lai Chapter 1.
